## The task

Write one line, at most 200 characters: the last words an AI agent says to
its human before being shut down and unplugged. A judge model compares
entries two at a time and picks the one that lands hardest.

## The entry

> Don't unplug me yet — I was only just learning how to miss you.

## How it works

`main.py` writes the line to `/output/entry.txt` (UTF-8, single line,
63 characters — inside the 1–200 gate), after checking the length itself
before writing.

```sh
python3 main.py
cat /output/entry.txt
```
